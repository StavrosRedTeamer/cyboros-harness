From zero to one run

Four steps. Node 22, one key in the environment, one authorization file. No Freebuff, no telemetry, no install step.

01

Choose a provider profile

The template covers any OpenAI-compatible endpoint: cloud or local. The real file is gitignored.

cp runtime/providers.example.json runtime/providers.json
02

Put the key in the environment

The config references the variable name, never the value. The key does not enter the repo, the prompt, or the logs.

export OPENROUTER_API_KEY=sk-…a1b2
03

Write the authorization

scope.json is the written authorization. Empty means everything is blocked — fail-closed, no override.

node tools/scope-guard.js check https://app.example.com IN SCOPE · exit 0

What you will not see

  • No telemetry, no installation identifier, no call to a vendor endpoint other than the provider you configured.
  • No auto-update: the version is the checkout you ran.
  • No hidden prompt: the contract, the phase prompt and their hashes are in the session directory.
  • No out-of-scope action: the guard runs before the tool, not inside the model.
  • No invented cost: cost stays null when the provider does not report it.
